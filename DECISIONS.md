## RL-D001 — Решение Owner о языке и навигации

**Дата:** 09.10.2026  
**Решение:** русский язык утверждён единственным смысловым языком Research Lab на нынешнем этапе. [Методология v0.4](./Methodology/methodology_v0.4.md) вводит уточнённый §1.1 на основании [CS-RL-003](./Development/Change-Sets/CS-RL-003-Research-Language-Norm-Proposal.md). Английские технические ID, имена файлов и формальные статусы, а также цитаты источников допускаются с русским смысловым объяснением. Исторические outputs не отменяются и не переводятся массово.

Утверждено [правило навигации и трёх уровней журналов](./Processes/Documentation_and_Decision_Records.md). Корневой README показывает проекты и запросы в Formation; проектный README показывает корпуса и gate; README книжного цикла показывает принятую редакцию каждого этапа. Ведение распределено между Lead на уровне проекта/этапа и Director на уровне лаборатории.

**Переход:** [RL-WAVE-2/RUN.md](./Development/Validation-Runs/RL-WAVE-2/RUN.md) остаётся неизменённой историей Events 001–072. Состояние IP-001 Stage 2 определяется [Event 072](./Development/Validation-Runs/RL-WAVE-2/RUN.md#event-072--ip-001-acts-rr-lead-focused-re-check-r1--accept-stage-2); RQ-RL-002 Installation сдан в [Event 070](./Development/Validation-Runs/RL-WAVE-2/RUN.md#event-070--rq-rl-002-project-lead-installation-handoff-первый-limited-review). Новые журналы ссылаются на эти решения, не принимают их повторно.

**Граница:** изменение языка и навигации не активирует Stage 3 IP-001, исполнение RQ-RL-002 или новые полномочия ролей. Для активного этапа сохраняется версия Methodology, закреплённая его назначением; следующее назначение явно фиксирует применимую версию.

**Ответственный за дальнейшую синхронизацию:** Director на уровне лаборатории; Project Lead на уровне проекта и этапа; Owner на следующем gate.
