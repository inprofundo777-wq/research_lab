# IP-001 — межкнижное сопоставление

**Состояние на 19.10.2026:** не активировано. Деяния, Римлянам и 1 Коринфянам имеют принятые предварительные Stage 0–3 и открытые вопросы; 2 Коринфянам ещё до отбора Stage 0 по условному решению D053. Это не даёт межкнижного вывода. Здесь будут сопоставляться самостоятельно исследованные книги после отдельного решения Owner, с учётом степени их проверки и закрытия. Предварительные книжные группы не становятся автоматически общими новозаветными выводами.

[Принятое дополнение к Protocol v0.2](../IP-001_Protocol_Addressing_and_Stage3_Handoff_Addendum_v0.1.md) закрепляет префиксы книжных U/G при внешней ссылке и условия будущего реестра NT-T по [IP-001-D029](../DECISIONS.md#ip-001-d029--owner-принятие-общей-установки-r1-по-маршруту-a-и-ограниченного-дополнения-protocol). **Ни одного NT-T пока не присвоено; межкнижный анализ не разрешён.** Исходный [проект Director](../Planning/IP-001-Межкнижная-классификация-и-книжное-закрытие-v0.1.md) сохраняется как история проектирования. Состояние книг и точные результаты: [паспорт IP-001](../README.md).
