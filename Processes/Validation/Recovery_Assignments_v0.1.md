# Research Lab Role System v0.1 — Fresh-Context Recovery Assignments

**Status:** Ready for Controlled Validation  
**Scope:** Wave 1 only  
**Write authority:** none  
**Full IP-001 restart:** not authorized

## Common rule

Each test uses a new isolated branch. The only initial role link is the named role README. The branch must independently recover the required governing documents, version, Package, boundaries, output and return route.

Every result must be one whole Markdown report:

~~~markdown
# Recovery Test — [Role]

## Recovered Identity
## Governing Documents
## Authority and Boundaries
## Installed Package and Modes
## Expected Output
## Stop Conditions
## Return Route
## Verdict
PASS / PARTIAL / FAIL
## Missing or Excessive Documentation
~~~

No test may modify GitHub, Research outputs, IP-001 status or role packages.

# Wave 1 disposition

- ADOPT;
- TEST FURTHER;
- REVISE;
- DEFER.

Wave 2 Formation Pilot remains blocked until:

1. Wave 1 disposition exists;
2. Strategist/Owner explicitly hands off one real bounded Research Request;
3. Owner authorizes the Formation Pilot.
