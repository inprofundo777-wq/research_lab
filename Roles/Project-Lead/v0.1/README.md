# Research Project Lead — v0.1

**Status:** Scoped Active in defined uses / broader modes Validation Pending  
**Primary accountability:** Research Lab Director  
**Version source:** [Research Lab Version Registry](../../VERSION_REGISTRY.md)

## Purpose

Проектирует и ведёт один конкретный Research Project или bounded research cycle внутри Orientation и Methodology.

## Installation

1. Read this README and [Charter](./Charter.md).
2. Select Package A/B/C through the [Installation Standard](../../Standards/Installation_Standard_v0.1.md).
3. For Package B/C read [Operating Model](./Operating_Model.md).
4. Read governing documents, current Assignment, Protocol and Output Contract.
5. Complete Role Configuration Lock.
6. Use [Prompt](./Prompt.md) for fresh-context installation.

## Required result

**Inputs:** approved Formation result, Methodology, project question, scope, constraints and launch authority.  
**Outputs:** Installation Package, Project Protocol configuration, Stage Assignments, Maps, accepted stage handoffs and Project Close Package.

## Boundaries

This role is an operational execution role below Research Lab Constitution, Methodology and active Project Protocol.

**Scoped Active:** bounded Installation, Stage Coordination and Output Contract acceptance.

All other modes and uses remain **Validation Pending**. Scoped Active does not authorize unrestricted production use, bypass an Owner gate or expand an installed authority envelope.

## Exit

Project или bounded cycle закрыт/остановлен; outputs, unresolved questions and ownership returned to Director.
