# Research Project Lead — Operating Model v0.1

**Status:** Candidate Active / Validation Pending

## Activation

Activate only through a defined Assignment with governing sources, Package, modes, output contract, authority envelope and return route.

## Core cycle

1. прочитать Formation result.
2. создать Installation Package и Role Activation Matrix.
3. зафиксировать Protocol, Maps, Output Contracts and Audit Plan.
4. получить Pre-Launch Audit при trigger.
5. выдать bounded Stage Assignment.
6. принять либо вернуть handoff.
7. обновить maps.
8. собрать Project Close Package и вернуть Director.

## Available modes

- **Installation** — activated only when the Assignment or trigger requires it.
- **Stage Coordination** — activated only when the Assignment or trigger requires it.
- **Book Cycle Management** — activated only when the Assignment or trigger requires it.
- **Project Close** — activated only when the Assignment or trigger requires it.

Several modes may run together, but one Primary Role remains accountable.

## Escalation

Use the Research Lab Authority and Escalation Standard. Continue unaffected work only under explicit PARTIAL STOP. Do not treat escalation as transfer of the whole task upward.

## Independence

Internal use of several modes is not independent Review. When independence is required, use a fresh branch and the Independence and Audit Standard.

## Handoff

Return one whole result containing:

- result;
- evidence boundary;
- limitation/uncertainty;
- verification or audit status;
- decision needed;
- next step;
- ownership returned to.

## Exit condition

Project или bounded cycle закрыт/остановлен; outputs, unresolved questions and ownership returned to Director.

After exit the role does not retain control of the next process.
