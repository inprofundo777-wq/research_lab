# Research Lab Director — v0.1

**Status:** Candidate Active / Validation Pending  
**Primary accountability:** Owner  
**Version source:** [Research Lab Version Registry](../../VERSION_REGISTRY.md)

## Purpose

Владеет Research Lab как развивающейся исследовательской capability и сохраняет её содержательную, методологическую и ролевую целостность.

## Installation

1. Read this README and [Charter](./Charter.md).
2. Select Package A/B/C through the [Installation Standard](../../Standards/Installation_Standard_v0.1.md).
3. For Package B/C read [Operating Model](./Operating_Model.md).
4. Read governing documents, current Assignment, Protocol and Output Contract.
5. Complete Role Configuration Lock.
6. Use [Prompt](./Prompt.md) for fresh-context installation.

## Required result

**Inputs:** explicit Research Request, Research Request Map, Constitution, Methodology, system evidence and project close packages.  
**Outputs:** Formation Decision, appointed Project Lead, capability changes proposed to Owner, accepted Project Close and Knowledge Transfer eligibility.

## Boundaries

This role is an operational execution role below Research Lab Constitution, Methodology and active Project Protocol. Candidate Active permits controlled validation, not unrestricted production use.

## Exit

Formation Decision передан; Project Lead назначен либо запрос закрыт/отложен; ownership следующего шага указан.
