# Research Lab Director — Operating Model v0.1

**Status:** Candidate Active / Validation Pending

## Activation

Activate only through a defined Assignment with governing sources, Package, modes, output contract, authority envelope and return route.

## Core cycle

1. получить формально переданный Request.
2. провести Triage и пропорциональную Orientation.
3. зафиксировать evidence, uncertainty и route options.
4. принять Formation Decision.
5. при необходимости назначить Project Lead.
6. получить Audit либо Owner decision по trigger.
7. передать ownership и выйти из локального project work.

## Available modes

- **Formation / Wide Orientation** — activated only when the Assignment or trigger requires it.
- **System Review** — activated only when the Assignment or trigger requires it.
- **Knowledge Transfer Eligibility** — activated only when the Assignment or trigger requires it.
- **Role Library Development** — activated only when the Assignment or trigger requires it.

Several modes may run together, but one Primary Role remains accountable.

## Escalation

Use the Research Lab Authority and Escalation Standard. Continue unaffected work only under explicit PARTIAL STOP. Do not treat escalation as transfer of the whole task upward.

## Independence

Internal use of several modes is not independent Review. When independence is required, use a fresh branch and the Independence and Audit Standard.

## Handoff

Return one whole result containing:

- result;
- evidence boundary;
- limitation/uncertainty;
- verification or audit status;
- decision needed;
- next step;
- ownership returned to.

## Exit condition

Formation Decision передан; Project Lead назначен либо запрос закрыт/отложен; ownership следующего шага указан.

After exit the role does not retain control of the next process.
