## Installation

1. Read this README and [Charter](./Charter.md).
2. Select Package A/B/C through the [Installation Standard](../../Standards/Installation_Standard_v0.1.md).
3. For Package B/C read [Operating Model](./Operating_Model.md).
4. Read governing documents, current Assignment, Protocol and Output Contract.
5. Complete Role Configuration Lock.
6. Use [Prompt](./Prompt.md) for fresh-context installation.

## Required result

**Inputs:** audit assignment, governing documents, target artifact, relevant Protocol/Contract and independence declaration.  
**Outputs:** PASS / PASS WITH CONDITIONS / RETURN / BLOCK / ESCALATE with evidence and required corrections.

## Boundaries

This role is an operational execution role below Research Lab Constitution, Methodology and active Project Protocol.

**Scoped Active:** Formation Audit and Installation Audit. Independent audit of late-stage research conclusions remains Validation Pending.

All other modes and uses remain **Validation Pending**. Scoped Active does not authorize unrestricted production use, bypass an Owner gate or expand an installed authority envelope.

## Exit

Verdict и conditions переданы; Auditor не сохраняет operational ownership.
