# Research Lab — Role Installation Standard v0.1

**Status:** Candidate Active / Validation Pending

## Installation formula

~~~text
Primary Role
+ optional Secondary Role
+ Package A/B/C
+ activated Modes
+ Current Source
+ Protocol
+ Assignment
+ Output Contract
+ Authority Envelope
+ Return Route
= installed working configuration
~~~

Only one Primary Role owns the current result. Multiple modes may be active simultaneously.

## Packages

### Package A — Minimal

For bounded, low-risk work with a clear source and output. Requires role README and Charter, current Assignment, governing source, output and return route.

### Package B — Standard

Default for normal stage work. Adds Operating Model, active Protocol, Role Configuration Lock, relevant previous handoff and verification triggers.

### Package C — Extended

For Formation, Installation, Synthesis, Audit, new project types, cross-corpus conclusions, material uncertainty or high-risk decisions. Adds wider governing context, dependencies, provenance, alternative evidence, explicit audit plan and migration/rollback boundaries.

Package depth does not change authority.

## Triggers to deepen the package

Move A → B or B → C when scope expands, material ambiguity appears, independent verification becomes necessary, more than one project is affected, authority becomes unclear or a conclusion may influence Methodology, Constitution or downstream application.

## Recovery Stop

Stop and return BLOCKED if current role version, governing source, scope, authority, required Protocol, Output Contract, independence condition or return route is missing or conflicting.

Installation is complete only when the role can state what it may do, what it may not do, what result is required and to whom ownership returns.
