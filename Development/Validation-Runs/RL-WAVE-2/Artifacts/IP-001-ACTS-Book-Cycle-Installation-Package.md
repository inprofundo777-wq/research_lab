## 3. Book-cycle architecture and transition gates

### Pre-Stage capability gate
До полного книжного исполнения проводится CV-IP-001-ACTS-01 из §7. Это не Stage 0 и не исследование книги. Переход к Stage 0 возможен только после принятого capability result и отдельного Owner authorization.

### Stage 0 — Book Corpus Map
Функция: последовательный просмотр всей книги по RST и Research Criteria без historical answer key.
Research units: гибкие narrative/pericope units; aggregation допустима, если сохраняется passage-level reason.
Output: coverage ledger Acts 1–28; candidate loci и criterion/reason; «Требует проверки» для неясного субъекта/перевода; нужные negative/contextual boundary cases; подтверждение historical isolation.
Переход: книга просмотрена; gaps отсутствуют или названы; каждый candidate recoverable; Lead принимает Stage 0.

### Stage 1 — Primary Observation
Contract: IP-001 Primary Observation Output Contract v0.2.
Granularity: passage/episode/chapter/related units, пока каждая significant unit recoverable; one chapter = one file не обязательно.
Output: Research Unit; Evidence; Attribution; при необходимости Direct/Mediated Action, Role, Relation, Result, Theological Connection; INCLUDE/BORDERLINE/CONTEXTUAL/EXCLUDE; Observation; material Limitation/Uncertainty; trigger-based Confidence/Verification.
Переход: все Stage 0 candidates имеют local judgment; omissions/BORDERLINE/UNRESOLVED/flags видимы; reasoning recoverable без historical output; Lead принимает completeness.

### Stage 2 — Repetition / Stable Evidence Map
Compact book map со ссылками на rr-001. Repetition отделено от strong singular и negative evidence.
Переход: repetitions traceable; singular/negative evidence сохранены; disputed cases не превращены в pattern по умолчанию.

### Stage 3 — Provisional Groups / Classification
Groups содержат type of warrant, constituent rr-001/002 refs, counter-evidence, overlaps, exclusions, confidence и Verification queue.
Переход: groups не превращают Relation/Mediation/theological significance в Direct Christ Action; supporting/limiting evidence и verification queue видимы.

### Material Verification gate
Проверяются только вопросы, способные materially изменить attribution, judgment, Action/Relation/Mediation distinction, strong singular finding, major group или proposed book conclusion. Philological/translation/contextual checks trigger-based. Независимые triggers — §8.
Переход к Stage 4: material flags resolved/bounded; required independent verification completed/accepted; отдельный Owner authorization Stage 4.

### Stage 4 — Book-level Close
Synthesis только о Деяниях: repeated findings, strong singular evidence, negative evidence, book-specific features, attribution boundaries, unresolved matters, proportional confidence.
Book-close authority currently Validation Pending. Stage 4 не начинается автоматически. Нужен отдельный Owner gate и решение dependency §9.
Stage 5/cross-book synthesis не устанавливается.

## 7. CV-IP-001-ACTS-01 — Narrative Book-scale Readiness Check

Purpose: проверить не знание выводов Деяний, а способность удерживать IP-001 discipline на распределённой выборке повествовательной книги до Stage 0.

При отдельном Owner authorization Researcher получает только заранее установленную Lead выборку из четырёх малых, разнесённых по книге units, без corresponding historical doc-* как рабочего входа:
1. явный candidate Christ agency;
2. место с риском ошибочного присвоения Father/Spirit/Human agency Христу;
3. mediation/relation case;
4. ambiguous/borderline case с возможным Verification Flag.

Чтобы check не стал partial Stage 0, sample не является corpus map и не используется как окончательное покрытие. Конкретные loci фиксируются только в execution assignment после Owner approval по структурным признакам biblical text/Protocol, не по historical findings.

Required per unit: evidence; attribution; action/relation distinction; provisional judgment; observation; material uncertainty; verification trigger if needed. Дополнительно: aggregation rationale, один plausible over-attribution risk, historical-isolation declaration и capability status PASS / PASS WITH LIMITS / FAIL.

Lead принимает PASS только если все units locally recoverable, нет material subject-attribution error, ambiguity/negative evidence сохранены, historical answer key не использован, Relation/Mediation не смешаны с Direct Agency и compression не разрушает reasoning.

PASS WITH LIMITS: material attribution error отсутствует, но есть повторяемая granularity/verification weakness, которую можно ограничить Stage 0 condition.

FAIL: material attribution error; historical answer-key use; systematic over-attribution; потеря material ambiguity/negative evidence; unrecoverable evidence→judgment; либо необходимость полномочий вне bounded textual scope.

FAIL/material dependency → STOP → Owner. Stage 0 не активируется. Возможные routes: targeted clarification + repeat bounded check; alternate Researcher; independent co-review configuration; scope redesign.

PASS не валидирует Stage 4 synthesis и не создаёт unrestricted full-book authority.

## 8. Independent verification plan

Independent verification required for:
- material ambiguous/disputed attribution changing judgment;
- Direct Christ Action resting on mediation, pronoun/syntax, translation or contextual inference;
- strong singular evidence materially affecting book conclusion;
- negative evidence materially limiting a major group;
- material doc-* vs rr-* divergence affecting synthesis;
- Stage 3 group depending on collapsed Action/Relation/Mediation;
- proposed Stage 4 synthesis and material exclusions underlying it.

Routine HIGH-confidence observations do not require independent re-review merely by existing.

Research Auditor v0.1 Scoped Active may audit Installation only; current scope does not cover subject-matter verification or book close. Fresh Researcher Independent Review/Re-check mode is Validation Pending for book-level verification and requires separate Owner-authorized capability validation/assignment.
